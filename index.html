Claude Certified Architect – Foundations [CCAR-F]
CCAR-F · ÍNDICE DEL CURSO

Índice del curso

El Claude Certified Architect – Foundations (CCAR-F) es un examen oficial de Anthropic, gestionado vía Pearson VUE, que evalúa la capacidad de diseñar, configurar y operar sistemas agénticos con Claude en producción. Este curso organiza el temario en un bloque transversal de fundamentos (Bloque 0) y cinco bloques alineados con los dominios del blueprint oficial, cada uno con su guía de estudio y su quiz de práctica. Marca tu avance con el botón de cada ficha: el progreso automático de guía y quiz se calcula solo cuando ya has interactuado con esos recursos en este navegador.

01 — Blueprint del examen

Dominios y pesos

Cinco dominios evaluables suman el 100% de la puntuación; el Bloque 0 de este curso es transversal y no tiene peso propio en el blueprint, pero sustenta la mecánica de base (API, tool use, bucle agéntico) que aparece como distractor en preguntas de los cinco dominios.

02 — Casos de uso

Qué sabrás construir

Al terminar este curso serás capaz de diseñar y configurar sistemas como estos — calcados de los escenarios de producción reales que usa el propio examen para plantear sus preguntas:

D1 · Agentic Architecture & Orchestration

Un agente de soporte al cliente que consulta pedidos y datos de cliente por MCP, aplica la política de reembolsos y devoluciones, y escala a un humano con un resumen completo del caso cuando la ambigüedad lo requiere.

D1 · Agentic Architecture & Orchestration

Un sistema multiagente de investigación donde un coordinador reparte búsqueda web, análisis de documentos y síntesis entre subagentes especializados, y entrega informes citados aunque las fuentes se contradigan entre sí.

D2 · Tool Design & MCP Integration

Un agente de productividad que explora un codebase heredado y desconocido, entiende su estructura y genera código repetitivo o refactors, combinando herramientas nativas (Read, Bash, Grep) con servidores MCP propios.

D3 · Claude Code Configuration & Workflows

Un flujo de trabajo de Claude Code a medida del equipo, con CLAUDE.md, comandos personalizados y reglas por carpeta, decidiendo cuándo dejarlo planificar antes de tocar código y cuándo darle vía libre para ejecutar directamente.

D3 · Claude Code Configuration & Workflows

Una integración de Claude Code en el pipeline de CI/CD que revisa cada pull request, genera casos de prueba y da feedback útil sin saturar al equipo de falsos positivos.

D4 · Prompt Engineering & Structured Output

Un sistema de extracción que convierte documentos no estructurados (facturas, contratos, formularios) en datos validados contra un esquema JSON, listos para el sistema aguas abajo, gestionando los casos límite sin romper la cadena.

03 — Tu avance

Progreso del curso

0%

Cada bloque aporta la media de sus dos barras (guía leída + aciertos del quiz; 0% sin datos, 100% si está marcado completado, a mano o automáticamente); el simulacro aporta 100% en cuanto tiene un intento terminado (sin exigir aprobar el corte) o 0% mientras no lo tenga; la barra global es la media de esos 7 componentes — 6 bloques + simulacro — sobre el curso completo, aunque los bloques 1–5 sigan «Próximamente». Las barras de cada ficha solo tienen datos si abres esos recursos desde este mismo origen (mismo sitio o carpeta) en este navegador; si no hay datos, se muestran como «—».
